Enrollment steps

1

Generate key on YubiKey

Run this on the machine with the YubiKey inserted:

ykman piv keys generate --algorithm ECCP256 \
  --touch-policy CACHED 9a /tmp/pubkey.pem
2

Generate CSR

ykman piv certificates request \
  --subject "CN={{.EnrollUser.Username}},emailAddress={{.EnrollUser.Email}}" \
  --hash-algorithm SHA256 9a /tmp/pubkey.pem /tmp/request.csr
3

Paste CSR below and sign

4

Import certificate to YubiKey

After signing, save the certificate and import it:

ykman piv certificates import 9a /tmp/client.crt
